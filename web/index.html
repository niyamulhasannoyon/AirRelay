About AirRelay

Designed to transfer files instantly on any device, anywhere in the world.

AirRelay is a peer-to-peer file-sharing application designed for fast, seamless cross-network file distribution with end-to-end encryption.

No account signups or software installations required. Transfer gigabytes of data between Mac, Windows, Linux, iOS, and Android directly through modern web browsers.

Direct WebRTC DataChannel Engine

Files are transferred point-to-point via WebRTC DataChannels. With strict backpressure flow control (<64 KB buffered queue) and direct disk streaming via the File System Access API and Service Worker pipelines, files of any size stream smoothly without browser memory bloat or socket flooding.

A lightweight signaling server coordinates initial peer discovery and ICE exchange. Once connected, transfers flow completely peer-to-peer with DTLS encryption. File contents never touch the server.
